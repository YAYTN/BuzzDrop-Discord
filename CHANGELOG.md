# Changelog

## 1.0.0

First release, for BetterDiscord and Vencord: right-click a message that contains a `BZ://` or BuzzHeavier link and choose **Download with BuzzDrop**. Several links in one message are sent together. If BuzzDrop isn't installed (Windows), it offers its download page instead of doing nothing.

The menu item has a small download icon in the style of Discord's own menu icons.
